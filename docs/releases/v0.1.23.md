# QBRemote 0.1.23（24）更新说明

## 中文

- 修复 qBittorrent 5.2+ 无法连接：5.2 登录成功返回 204 空响应，此前被误判为登录失败，服务器一直显示离线。
- 修复 qBittorrent 5.2+ 添加种子的结果判断：上传 .torrent 文件成功却提示失败、磁力链接失败却显示成功的问题；部分失败时会提示成功与失败的数量。
- 新增备用限速一键切换：首页速度卡片右上角的乌龟按钮可一次切换所有在线服务器（显示"全局备用限速 / 部分备用限速"），服务器仪表盘上可单独切换；限速设置弹窗顶部也新增了"常规 / 备用"切换。首次使用时会有引导提示。
- 修复部分 Transmission 服务器打开种子详情时报错（"RPC path not found / Non-JSON response"）：兼容字段类型不标准的响应；如仍无法解析，错误信息会指出具体字段。
- 文案优化："全局限速"更名为"限速设置"。

## English

- Fixed connecting to qBittorrent 5.2+: its successful login now returns an empty 204 reply, which was treated as a failed login and left the server offline.
- Fixed add-torrent results on qBittorrent 5.2+: .torrent uploads no longer report failure on success, and magnet failures are no longer shown as success; partial failures report the counts.
- New one-tap alternative ("turtle") speed limits: the turtle button on the home speed card switches every online server at once (Global / Partial alt limits), each server dashboard has its own, and the Limit settings dialog gains a Normal / Alternative switch at the top. A one-time hint explains it.
- Fixed the torrent detail error on some Transmission servers ("RPC path not found / Non-JSON response") by tolerating off-spec field types; if a reply still cannot be read, the error now names the field.
- Renamed "Speed limits" to "Limit settings".
