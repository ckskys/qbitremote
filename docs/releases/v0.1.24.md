# QBRemote 0.1.24（25）更新说明

## 中文

- 修复正式版打开 Transmission 种子详情时报错（"Abstract classes can't be instantiated"）。
- 修复 Transmission 开启备用限速后仍显示常规限速的问题。
- 切换备用限速后，服务器卡片上的限速数值立即更新，不再延迟数秒后跳变；"一键切换全部"不再偶尔漏掉当前服务器。
- 点击下载完成通知会直接打开对应种子（必要时自动切换服务器）。
- 恢复默认图表卡片时与新建服务器的默认设置一致，qBittorrent 不再丢失"Tracker 站点占比"卡片。
- 首页实时速度图在长时间未打开后不再出现大段空白（"-23h"）。
- 筛选后种子列表为空时会说明原因，并提供"清除筛选"按钮。
- 下拉刷新换用 Material 3 样式；代码清理与稳定性改进。

## English

- Fixed the "Abstract classes can't be instantiated" error when opening a Transmission torrent in release builds.
- Transmission now shows the alternative limits while alternative speed mode is on.
- After a turtle (alt speed) switch, the limits on server cards update instantly instead of jumping a few seconds later; "switch all" no longer occasionally skips the active server.
- Tapping a download-complete notification opens that torrent, switching server if needed.
- "Reset cards" restores the same defaults a new server gets, so qBittorrent keeps its Tracker Site Share card.
- The home realtime speed chart no longer starts with a long gap ("-23h") after the app has been closed for a while.
- An empty, filtered torrent list now says why and offers "Clear filters".
- Material 3 pull-to-refresh; code cleanup and stability improvements.
