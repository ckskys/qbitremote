# QBRemote 0.1.22（23）更新说明

## 中文

- 全新简约界面：新字体与等宽数字、更克制的配色、更干净的卡片，以及新的应用图标。
- 种子列表：右滑暂停/继续、左滑删除，长按多选批量操作，下拉刷新；列表行改为紧凑的两行布局。
- 种子详情：顶部一眼可见关键数据，新增已连接用户列表与文件下载优先级，属性改为列表 + 弹窗编辑。
- 首页与服务器仪表盘：更醒目的速度读数，图表与世界地图重新设计。
- 连接测试更快（12 秒超时），错误提示更清晰且已本地化。
- 适配 Android 15+ 全面屏（edge-to-edge），支持预测性返回手势。
- 问题修复与性能优化。

## English (Google Play "What's new")

- Redesigned UI: a clean, minimal look with new fonts, calmer colors and a new app icon
- Torrent list: swipe to pause/resume or delete, long-press to multi-select, pull to refresh
- Torrent details: key stats at a glance, connected peers list, per-file download priority
- Home and server dashboards: bigger speed readouts and refined charts
- Faster connection tests with clearer error messages
- Bug fixes and performance improvements
