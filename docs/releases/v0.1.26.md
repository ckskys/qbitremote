# QBRemote 0.1.26（27）更新说明

## 中文

- 种子列表新增分组筛选面板：按状态、分类、标签、Tracker 服务器四组筛选，组内可多选、组间为"与"关系，替代原来的单选下拉。
- 每个筛选项后面显示实时候选数量，数量会随其他组的已选条件一起变化，避免点进去才发现是空的。
- 顶部筛选按钮显示出已选条件数量；列表上方有已选条件摘要，每条都能单独点掉。
- 筛选与搜索、排序可以同时生效；筛选后为空时会说明是筛选还是搜索造成的。
- 中文/英文文案同步补齐。

## English

- The torrent list gains a grouped filter panel: State, Category, Tag and Tracker site. Multiple values can be selected inside a group, groups combine with AND, replacing the old single-choice dropdowns.
- Every option shows a live matching count that already accounts for the other groups' selections, so you never drill into an empty result.
- The toolbar filter button shows how many conditions are active, and a summary above the list lets you remove any single condition.
- Filtering combines with search and sorting; an empty result now says whether the filters or the search caused it.
- Chinese and English strings kept in sync.
